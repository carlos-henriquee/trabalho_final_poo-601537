## SISTEMA DE ADOÇÃO DE ANIMAIS E GESTÃO DE ABRIGO
Esse é um sistema de adoção de animais desenvolvido pelo estudante Carlos Henrique Oliveira Sales, aluno do curso de Ciência da Computação na UFC, campus de Crateús, pela matrícula 601537. O sistema conta com mecanismos de login/cadastro de voluntarios e veterinarios com varias funcionalidades para cada cargo. Além disso, inclui um sistema de notificações em tempo real.
## Linguagem utilizada:

## Como rodar?
-  Abra o terminal da sua máquina e verifique se tem o git instalado:
```
    git --version
```
Se não tiver instalado, você pode visitar o site oficial: [Git](https://git-scm.com/)

-  Navegue até a pasta que deseja clonar o repositório:
```
    cd caminho/para/pasta
```  
- Rode este comando:
```
    git clone https://github.com/carlos-henriquee/trabalho_final_poo-601537
```  

- Rode o sistema:
```
    javac AppGestao.java
    java AppGestao
``` 
Caso nao tenha o java instalado, acesse: [Site](https://www.oracle.com/br/java/technologies/downloads/)
